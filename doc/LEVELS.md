# Tutorial - Job Interview(Skippable)
## Boss: Small, easily defeatable
## Scene: Asteroid field
## Purpose: Show how weapons and time travel works
## Script: 
Carrier ship appears, some introductory dialog outlines that this is a job interview for the piloting role for a venture.
The first task for the pilot is to go to a mark on the map.
The marks continue to appear, a light time constraint is being introduced.
Time constraint is being decreased, to force the pilot to use the thruster.
A brief pause of the game happens at the start of this section, where dialog explains boosting, and the task.
The last mark leads to a lonely deactivated android. The Pilot is prompted to destroy it through dialog.
Once destroyed, more dialog! "Oh that was our only captured drone, so we're gonna need you to undo it".
Pilot reverses time, drone is restored. Mine is attached to the ship.
Pilot is prompted to destroy the drone again with the other weapons.
Once the drone is destroyed by all the weapon types a boss appears. 
A checkpoint is being saved, so battle restart is from there.
The player tries to destroy the boss, inevitably fails.
A Dialog prompts the round restart method, at round start, the pilot realizes that the new friendly ships appearing is him in the past.
Some time travel paradoxical nonsense dialog ensues.
The boss is defeated by restarting the battle multiple times with multiple versions of the ship attacking it.
